A short, funny rant about an everyday annoyance — the man in the elevator
who watches the doors close on you and chooses not to hold them.

`main.py` (Python 3.13, standard library only) writes the rant to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validated to
1–400 characters, a single line, no trailing newline.

## Run

```sh
python3 main.py
```
